# Ontwerpen vóór de bouw

Schetsen die getekend zijn voordat er code van gemaakt is. Per map de
artboards (`*.dc.html`) en de indeling van het canvas (`canvas.json`).

- `foundationos/` — het publieke beginscherm van FoundationOS
  (`/apps/foundation/os-publiek.html`), bureau en telefoon.

Het samengestelde canvasbestand staat in `.gitignore`: dat is een
gegenereerd bestand van ~2 MB dat uit de artboards opnieuw te schrijven is.
