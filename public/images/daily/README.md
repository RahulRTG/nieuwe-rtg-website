# Dagelijkse RTG-schermen

Gemaakt met de ingebouwde imagegen-tool, 18 september 2026. AI-sfeerbeelden voor de goedgekeurde ontwerpen, geen ledeninhoud. De interface is HTML.

## pulse

Use case: photorealistic-natural. Asset type: editorial RTG app header photograph. An intimate Amsterdam canal-side cafe terrace in golden late afternoon, small empty tables, warm reflected sunlight, refined candid urban atmosphere. No recognizable people. Premium understated editorial photography, natural texture, warm onyx, ivory and champagne palette, realistic photography. Portrait 3:4 framing with subject in upper two thirds and darker bottom area suitable for a CSS fade, useful also cropped to landscape. One complete photograph, no UI, no text, no letters, no brand, no collage, no watermark.
